Arcade Flashback Classics

A retro arcade collection, called Arcade Flashback Classics, following the journey of three classic games packed together in one program. Join the fun on this adventure as you battle aliens, guide your snake, and flap through the sky to conquer every retro challenge.Imade this for Terra theme was antique and i love old games like flappy bird so this inspired me.made in pygame in vscode compiled with pyinstaller into one exe

Game Controls

Main Arcade Menu

Left / Right Arrow Keys (or A / D): Scroll through games

Spacebar / Enter: Select and launch game

Escape (ESC): Exit the launcher
<img width="1120" height="685" alt="Screenshot 2026-11-02 110617" src="https://github.com/user-attachments/assets/39ea47b1-0246-4042-bb87-ecb22fa8bebf" />


Space Invaders

Left / Right Arrow Keys (or A / D): Move player ship left / right

Spacebar / Up Arrow: Fire laser cannon

R: Restart after Game Over

Escape (ESC): Return to main menu

Snake

Arrow Keys (or W / A / S / D): Change snake direction
