Arcade Flashback Classics

A retro arcade collection, called Arcade Flashback Classics, following the journey of three classic games packed together in one program. Join the fun on this adventure as you battle aliens, guide your snake, and flap through the sky to conquer every retro challenge.

Installation Instructions

Extract the arcade-project.zip file on your computer.

Open the platformer-project folder.

Double-click menu.py to launch the arcade hub and start playing instantly!

Game Controls

Main Arcade Menu

Left / Right Arrow Keys (or A / D): Scroll through games

Spacebar / Enter: Select and launch game

Escape (ESC): Exit the launcher

Space Invaders

Left / Right Arrow Keys (or A / D): Move player ship left / right

Spacebar / Up Arrow: Fire laser cannon

R: Restart after Game Over

Escape (ESC): Return to main menu

Snake

Arrow Keys (or W / A / S / D): Change snake direction

R: Restart after Game Over

Escape (ESC): Return to main menu

Flappy Bird

Spacebar / Up Arrow: Flap wings / Jump

R: Restart after Game Over

Escape (ESC): Return to main menu
