Installation Instructions

    Extract the arcade-project.zip file to any location on your computer.
    Open the extracted folder.
    Double-click menu.exe to launch the arcade hub and start playing instantly!

Game Controls
Main Arcade Menu

    Left / Right Arrow Keys (or A / D): Scroll through games
    Spacebar / Enter: Select and launch game
    Escape (ESC): Exit the launcher

Space Invaders

    Left / Right Arrow Keys (or A / D): Move player ship left / right
    Spacebar / Up Arrow: Fire laser cannon
    R: Restart after Game Over
    Escape (ESC): Return to main menu

Snake

    Arrow Keys (or W / A / S / D): Change snake direction
    R: Restart after Game Over
    Escape (ESC): Return to main menu

Flappy Bird

    Spacebar / Up Arrow: Flap wings / Jump
    R: Restart after Game Over
    Escape (ESC): Return to main menu
