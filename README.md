A retro arcade collection, called Arcade Flashback Classics, following the journey of three classic games packed together in one program. Join the fun on this adventure as you battle aliens, guide your snake, and flap through the sky to conquer every retro challenge.Imade this for Terra theme was antique and i love old games like flappy bird so this inspired me.made in pygame in vscode compiled with pyinstaller into one exe

## Game Controls

### Main Arcade Menu
- **Left / Right Arrow Keys** (or **A / D**): Scroll through games
- **Spacebar / Enter**: Select and launch game
- **Escape (ESC)**: Exit the launcher

  <img width="1123" height="686" alt="image" src="https://github.com/user-attachments/assets/fd28ecfc-dd2e-4b15-beca-0e3be2052e39" />




### Space Invaders
- **Left / Right Arrow Keys** (or **A / D**): Move player ship left / right
- **Spacebar / Up Arrow**: Fire laser cannon
- **R**: Restart after Game Over
- **Escape (ESC)**: Return to main menu

### Snake
- **Arrow Keys** (or **W / A / S / D**): Change snake direction
- **R**: Restart after Game Over
- **Escape (ESC)**: Return to main menu

### Flappy Bird
- **Spacebar / Up Arrow**: Flap wings / Jump
- **R**: Restart after Game Over
- **Escape (ESC)**: Return to main menu

### Tetris
- **Left / Right Arrow**: Move block horizontally
- **Up Arrow**: Rotate block
- **Down Arrow**: Soft drop (move down faster)
- **Spacebar**: Hard drop (instant drop)
- **Escape (ESC)**: Return to main menu

### Breakout
- **Left / Right Arrow**: Move paddle
- Spacebar: Launch ball / Restart after Game Over
- **Escape (ESC)**: Return to main menu

### Pong
- **W / S**: Move left paddle up and down
- **Up / Down Arrow**: Move right paddle up and down
- **R**: Restart after Game Over
- **Escape (ESC)**: Return to main menu

### Pool
- **Mouse Move**: Aim cue stick
- **Left Click & Drag / Release**: Set shot power and shoot
- **R**: Restart / Reset table
- **Escape (ESC)**: Return to main menu

### Pinball
- **Left / Right Arrow**: Control left and right flippers
- **Down Arrow / Spacebar**: Pull and release plunger to launch ball
- **R**: Restart after Game Over
- **Escape (ESC)**: Return to main menu
